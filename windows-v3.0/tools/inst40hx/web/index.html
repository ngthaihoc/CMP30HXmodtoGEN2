BIOS SETUP GUIDE

Hướng Dẫn Nạp Key BIOS & Giữ Tensor Core

⚠️ Hãy dùng điện thoại chụp lại hướng dẫn này trước khi khởi động lại máy tính!
Vị trí file chứng chỉ (CMP40HX_Key.cer):
1. Ổ hệ thống: C:\CMP40HX_Key.cer
2. Màn hình Desktop: Desktop\CMP40HX_Key.cer
BƯỚC 1
Vào BIOS Setup: Tìm tab Security hoặc Boot → Chọn Key Management (Nếu đang ở Standard Mode, đổi sang Custom Mode).
BƯỚC 2
Nạp chứng chỉ vào db: Tìm Authorized Signatures (db) hoặc Append db → Chọn file CMP40HX_Key.cer từ ổ C hoặc Desktop → Nhấn Add/Append (Giữ nguyên các key Microsoft).
BƯỚC 3
Bật Secure Boot: Đặt mục Secure Boot thành ENABLED.
BƯỚC 4
Lưu cấu hình: Nhấn F10 → Chọn Yes để Khởi động lại vào Windows.
